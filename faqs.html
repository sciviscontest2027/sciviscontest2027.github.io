Frequently asked questions

Answers to the questions we expect most often. More will be added as they come in.

Who can participate?

The contest is open worldwide to students, researchers, industry professionals, and visualization enthusiasts. Individuals and teams are both welcome; we suggest teams of about six or fewer so that authorship stays clear.

Can one team submit to both tracks?

A team may submit one entry per track, but each entry must be a distinct submission with its own report and video. The same visualization system may not be entered in both tracks.

Do I need to address every question in Tasks 1 and 2?

No. Focus on what you can do well. The jury values depth, soundness, and insight over breadth. That said, the contest is about the connection between the strut level and the part level, so entries that address only one scale will be at a disadvantage.

Do I need to work on all nine specimens?

For the Visualization Design Track, we strongly encourage it (cross-specimen comparison is part of Task 2), but you may concentrate on a subset if you explain why. For the Agentic AI Track, a CSV for every specimen is required, because the scored specimen is drawn at random after the deadline.

The STL/JSON is not aligned with the CT data. Is registration part of the challenge?

Yes, if you want it to be. One specimen is provided with a pre-aligned JSON graph so that you can develop analysis methods first. Solving registration for the remaining specimens is a legitimate contribution, as is a method that does not need the design at all.

For the Agentic AI Track, can the agent use existing visualization software?

Yes. The agent may call any tool you give it (VTK, napari, PyVista, plotting libraries, your own MCP servers). Describe in the report what the agent was given and what it created itself.

For the Agentic AI Track, may the agent write the report?

No. The report is where you explain the agent to us (see the track description and What to include); an agent narrating its own run is not useful evidence for the jury. Agent-generated figures are welcome in the report if labeled as such.

Can I use the LatticeAnalytics paper's methods?

Absolutely. The contest is explicitly designed to build on and go beyond that work, in particular toward missing/disconnected struts and the part level.
